人与 AI 一起调板

给 AI 留好Agent 控制通道，人随时用 Web / IDE / SSH 介入——同通道、不互斥。 本地能控，开 Tunnel 远程也能控；控板 + Share 传文件，一套工具跟全程。

产品设计框图 部署形态 下载
01

人机共研，AI 有专用通道

Agent 走 HTTP/WS 控板、传文件；人开网页旁观或接手。并行不抢。

  • AI：Agent 接口开箱即用
  • 人：Web · IDE · 入站 SSH
  • 同一会话，随时介入
02

本地控得了，远程也一样

实验室同机直连；异地开 Tunnel 映同一套入口。再加 Share 传文件、扫描找板。

  • Tunnel：人与 AI 都能远程进
  • Share：上传一次，板多协议拉
  • 发现：扫局域网主机与板

Tools

工具说明

按角色拆开：接入 · 控对象 · 文件 · 远程 · 发现。

人的接入 · AI 的接口

别跟控板后端混在一起

  • 人：Web 网页 · IDE · 入站 SSH
  • AI：Agent 接口（HTTP / WS）
  • 本地直连或 Tunnel 远程，同一套

串口桥 · SSH Link

控受控板 / 受控主机

  • 串口桥：COM/tty，无网可调
  • SSH Link：出站连板或主机
  • 人机同会话旁观，不互斥

Share 共享目录

{work}/share

  • 人网页上传 · AI HTTP 上传
  • 板：TFTP / NFS / HTTP 拉
  • 上传一次，按启动阶段换协议

Tunnel · 发现扫描 · 继电器

远程 · 找机器 · 电源

  • Tunnel：人与 AI 远程操控
  • 发现：UDP + windows_manager 扫描
  • 继电器：电源 · 重启 · Upgrade
