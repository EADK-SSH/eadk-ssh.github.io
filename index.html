本地也能控，远程也能控

人走 Web / IDE / 入站 SSH；AI走 Agent 接口。 底下用串口桥 · SSH Link控受控板/主机，用Share传文件； Tunnel把同一套入口映到远程；局域网还能扫描发现本机与板卡。

产品设计框图 部署形态 下载
01

接入面分清：人一条路，AI 一条路

人用网页、IDE、入站 SSH；AI 主要用 Agent HTTP/WS。本地直连或经 Tunnel 远程，能力一样。

  • 控对象：串口桥 / SSH Link → 受控板或主机
  • 入站 SSH 是人的接入通道，不是控板后端
  • 人机同看一条会话，并行不互斥
02

Share + Tunnel + 发现，一个进程里

上传用网页/HTTP；板用 TFTP/NFS/HTTP 拉。Tunnel 远程操控；扫描工具找本机与可发现板。

  • Share：人与 Agent 同一目录
  • Tunnel：人与 AI 都能远程进
  • 发现：UDP + windows_manager 扫描

人的接入 · AI 的接口

别跟控板后端混在一起

  • 人：Web 网页 · IDE · 入站 SSH
  • AI：Agent 接口（HTTP / WS）
  • 本地直连或 Tunnel 远程，同一套

串口桥 · SSH Link

控受控板 / 受控主机

  • 串口桥：COM/tty，无网可调
  • SSH Link：出站连板或主机
  • 人机同会话旁观，不互斥

Share 共享目录

  • 人网页上传 · AI HTTP 上传
  • 板：TFTP / NFS / HTTP 拉
  • 上传一次，按启动阶段换协议
