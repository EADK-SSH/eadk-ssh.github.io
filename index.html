串口与 SSH，一张 Web 面管完

把本机 串口 与远端 SSH Link 统一成 Dashboard + HTTP Agent API； 再加共享入站 ssh 板名@host。人与 AI 并行不互斥。

看框架图 下载便携包 Issues
01

人用 Web / SSH，AI 用 HTTP

同一通道：浏览器终端旁观，Agent 走 REST/WS 发键与拉日志，互不抢占。

  • Dashboard 多板卡会话 + 热加载
  • Agent：/help 接口文档齐全
  • 共享入站 SSH：用户名 = 通道名
02

Share · TFTP · NFS 同根目录

传内核 / 设备树 / ramdisk：主机 HTTP 上传，板端 TFTP 或 NFS 拉取。

  • 网页多文件拖到当前目录即传
  • U-Boot serverip → TFTP
  • Linux mount -t nfs …:/share
