控板 + 传文件，一个工具全包

串口 / SSH 给人用 Web、给 AI 用 HTTP；再加共享目录：人与 Agent 网页或 HTTP 上传， 板子用 TFTP / NFS / HTTP 拉到本地。启动前也能调，并行不互斥。

产品设计框图 部署形态 下载
01

人与 AI 同通道，并行不互斥

人开网页看终端，AI 走 HTTP 发键 / 拉日志；还能 ssh 板名@主机 进来。

  • 串口：无网也能进 U-Boot / 内核日志
  • SSH Link：网口起来后高效控板
  • 一张 Dashboard 管多块板
02

共享目录：上传一次，板端多种拉法

内核 / DTB / rootfs 放进 {work}/share，主机侧网页或 HTTP 上传，板侧按阶段选协议。

  • U-Boot → TFTP（经典 serverip）
  • Linux 起来 → NFS 挂载或 HTTP 下载
  • 人与 Agent 同一目录，不另起文件服务器
Design

产品设计框图

人 / AI → ssh_bridge_manager（控板 + 共享目录）→ 板卡 × N。相对套件总图：本组件把 Share / TFTP / NFS / HTTP 文件通道 做进同一进程。

Deploy

部署形态

场景一：人 / AI / Bridge 同机。场景二：人 / AI 远程，Bridge + 板留守现场。协同方式相同。
